Namespace LunaFlow.Engine

Classes

Command

Represents a user-issued command within the LunaFlow system. A command consists of a name and optional arguments that drive game behavior.

CommandDispatcher

Responsible for routing incoming commands to the appropriate command handler. Maintains a registry of handlers and manages dispatch logic.

EngineHost

Acts as the entry point for the LunaFlow engine. Initializes the engine environment and hosts the main run loop.

GameEngine

Represents the core engine that processes game logic, player actions, and rule evaluation.

RuleEngine

Provides a central rule evaluation engine for LunaFlow. All game actions and consequences are evaluated through this system.

Interfaces

ICommandHandler

Defines the interface for handling a specific type of command. Implementers execute logic in response to a matching command name.

IGameEngine

Defines the contract for the core LunaFlow game engine. Exposes methods for initialization, input handling, and lifecycle control.
