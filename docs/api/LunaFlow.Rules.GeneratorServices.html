Namespace LunaFlow.Rules.GeneratorServices

Classes

RuleCodeClass

Represents a single class to be generated in the output file. Typically corresponds to one rule from the IR.

RuleCodeUnit

Represents the output of a code generation step: a C# file containing generated rule classes.

RuleExport

Entry point used to trigger the rule pipeline generation. Authors may invoke this manually to compile or emit rule outputs.

RuleGroupAttribute

Identifies a static class that groups related rule templates.

RuleIR

Represents a single parsed rule in the intermediate stage. Contains all data required for code generation.

RuleIRGroup

Represents a group of rules parsed from a single rule group class.

RuleParseContext

Provides context and input information to the rule parsing stage of the pipeline. Used to identify which assemblies or types should be inspected for rule definitions.

RulePipeline

Coordinates the full rule generation pipeline, from parsing to code generation to output.

RulePrototype

Represents a structured rule definition intended for NRules code generation. Contains all elements needed to synthesize a complete Rule-derived class.

RuleTemplateAttribute

Marks a static property returning a RulePrototype for inclusion in rule generation.

StandingRuleAttribute

Specifies that a rule or rule group requires the absence of a marker component in the context.

Interfaces

IRuleCompiler

Defines the interface responsible for emitting code files or compiling rules to assemblies.

IRuleIRGenerator

Defines the interface for converting parsed rules into a format suitable for code generation.

IRuleParser

Defines the interface for parsing rule declarations from author code into an intermediate representation.
